# 🏫 Escola Carrossel — Website Institucional

O **Escola Carrossel** é um site institucional responsivo desenvolvido para apresentar a proposta pedagógica, infraestrutura, modalidades de ensino e diferenciais de uma instituição focada em Educação Infantil e Ensino Fundamental. O projeto foi projetado com foco em usabilidade, performance e **captação de matrículas**.

## 🎯 Funcionalidades Principais

- **Banner Principal (Hero Section):** Destaque da proposta de valor com chamada para ação (*CTA*) direcionando para matrículas.
- **Quem Somos:** Apresentação da missão e história da instituição.
- **Níveis de Ensino:** Cards informativos cobrindo Educação Infantil, Ensino Fundamental I e Ensino Fundamental II.
- **Diferenciais Pedagógicos:** Seção dedicada a programas especiais (Robótica, Bilíngue, Esportes e Suporte Psicopedagógico).
- **Formulário Dinâmico:** Envio automático dos dados do responsável direto para o WhatsApp da escola.
- **Atendimento Rápido:** Botão flutuante do WhatsApp no canto inferior da tela.
- **Design Totalmente Responsivo:** Layout adaptado para celulares, tablets e desktops.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica do site.
- **CSS3:** Estilização responsiva com Flexbox, CSS Grid e variáveis.
- **JavaScript (ES6):** Manipulação de formulários e integração com a API do WhatsApp.
- **Font Awesome:** Ícones vetoriais modernos.
- **Google Fonts:** Tipografia (*Poppins*).
